# ちんちん侍

円になって遊ぶ飲み会ゲーム「ちんちん侍」のブラウザ版（スマホのホーム画面に追加できるアプリ）。ver 1.16.0。
全体3〜6人。1人でCPUと遊ぶか、オンライン対戦で友達がそれぞれのスマホから参加。空いた席はCPU。
変更の履歴は [CHANGELOG.md](CHANGELOG.md)（ゲーム内の「情報」タブのパッチノートと同じ）。
スタート画面は「遊ぶ」「キャラ」「設定」「情報」の4つのタブに分かれている。

## ルール
- 親は「ちんちん」「おちんちん」「侍」「ちんちん侍」のどれかを言って、自分以外の誰かを指す
- 「ちんちん」→ 指された人は何も言わず、そのまま次の言葉で誰かを指す
- 「おちんちん」→ 指された人が「びろーん」
- 「侍」→ 指された人が「シャキーン」
- 「ちんちん侍」→ 親も含めて全員で「ちんちん侍」
- 反応のあと、指された人が次の親になる
- 言い間違い・お手つき・時間切れは「切腹」。一人切腹したら勝負あり

続くほど制限時間が短くなります。

## デスマッチ
ルールで「デスマッチ」を選ぶと、切腹した人は脱落して、残りの人で続けます。最後の一人になったら決着。
脱落した人の次（時計回り）の人が親で再開します。

## CPUの強さ
- **弱い**: いつも30%の確率で失敗
- **普通**: 最初は0%。続いた回数がそのまま失敗確率（10回目なら10%）
- **強い**: 20回までは失敗0%で「ちんちん」を高速で回す。21回目から（回数−20）%で失敗

強さとは別に「CPUは絶対に負けない」をオンにすると、CPUは失敗しなくなり、切腹するのは人間だけになります（強さはスピードと言葉の選び方だけに効く）。

## モード
- **セリフボタン**: 言葉ボタンを押して、指す人をタップ（順番はどちらが先でもOK）
- **音声入力**: 言葉を声で言って、指す人をタップ。Web Speech API を使うので Chrome / Safari で、`https://` で開いてください。マイクが使えないとき（通話中など）は画面に知らせが出る

## 称号
- 勝負の中の出来事で称号がとれる（46個。銅・銀・金・虹・神話、隠し称号あり）。「称号」タブで一覧と装備
- 装備した称号はタイトル・対戦中の名前の下・オンラインの参加者一覧・結果画面に出る
- 判定は各自のスマホで行う（オンラインでも自分の分だけ）。練習・動きを見るでは数えない

## オンライン対戦
- タイトルの「オンライン対戦」→「部屋を作る」で4ケタの部屋番号ができる。相手は番号を入れるか、招待リンク（`?room=番号`）を開いて参加
- 6人まで。足りない席はCPU（「CPUなし」にすると参加者だけ）。ルールはホストが待合室の「ルールを変える」で変えられる（最初はホストのタイトル画面のルール）
- 対戦が終わったら、ホストの「待合室へ」で全員まとめて待合室に戻れる。入力モードや案内などは各自が待合室の「自分の設定」タブで変える
- ホストの端末が判定とCPUを受け持ち、参加者は自分の操作（言葉・指す人）を送るだけ。誰が言ったか分かるので、お手つきも正確
- 通信の遅れぶん、制限時間は0.5秒長い
- 「キャラの声を送る／受け取る」で、相手の声を自分のスマホで鳴らすかを選べる
- 途中で通信が切れた人の席はCPUが引き継ぎ、戻ってきたら本人に返す。ページを閉じてもタイトルの「部屋 ○○○○ に戻る」で戻れる。ホストが「部屋を出る」と部屋は閉じる
- 別のアプリに切り替えて通信が一時的に切れても、部屋は残る（ホストが45秒戻らなければ、参加者はメニューに戻る）
- 待合室と結果画面でチャット（60文字まで）。声付きの定型文（いざ、勝負！・お見事！など10個）は対戦中も右上の「定型文」から送れる

### オンライン対戦の準備（管理者が1回だけ・無料）
Firebase の無料プラン（Spark）だけで動きます。クレジットカードの登録は不要です。
1. https://console.firebase.google.com で「プロジェクトを作成」（名前は例えば `chinchin-samurai`。Googleアナリティクスはオフでよい）
2. 「構築 → Authentication → 始める → ログイン方法」で **匿名** を有効にする
3. 「構築 → Realtime Database → データベースを作成」。ロケーションは **シンガポール（asia-southeast1）**、**ロックモード** で作成
4. Realtime Database の「ルール」タブに、このリポジトリの `database.rules.json` の中身を全部貼り付けて「公開」
5. 「プロジェクトの設定（歯車）→ 全般 → マイアプリ」で **ウェブ（</>）** を追加し、表示された `firebaseConfig` の中身を `firebase-config.js` の `window.FIREBASE_CONFIG = { ... }` に貼ってコミット。`databaseURL` が入っていることを確認
6. GitHub Pages に反映されたら、タイトルに「オンライン対戦」ボタンが出る

- `firebase-config.js` の値は公開して大丈夫なもの（データの守りは `database.rules.json` で行う）
- `database.rules.json` を変えたら、Realtime Database の「ルール」タブに貼り直して「公開」する（変更があった版：1.1.0 チャット／1.7.0 途中から戻る／1.16.0 古い部屋の掃除）
- 無料枠の目安：同時接続100、保存1GB、ダウンロード月10GB。1試合のやり取りは数十KB程度なので、仲間内で遊ぶ分には十分
- `firebase-config.js` が `null` のままなら、オンライン対戦のボタンは出ず、ほかの機能はそのまま使える

## アプリとして使う（GitHub Pages）
- リポジトリの Settings → Pages で、Branch を `main`・フォルダを `/ (root)` にして保存。数分で `https://<ユーザー名>.github.io/chinchin-samurai/` で開ける
- スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように起動できる。一度開けば電波がなくても遊べる（オンライン対戦を除く）
- 更新したら `sw.js` の `CACHE` の番号と、`index.html` の `?v=` の番号・`APP_VERSION` を上げる（古いキャッシュが消えて新しい版になる）

## そのほかの機能
- **案内を出す（初心者向け）**（オンオフ可、最初はオフ）: 誰の番か・何と言えばいいかを画面の下に出す。親の金枠・指された人の赤丸・指せる人のぷくぷくもこのときだけ出る
- **スワイプモード**（オンオフ可、最初はオフ）: シャキーン・びろーんのボタンが消え、ボタンの下の場所を「／」とスワイプでシャキーン（ちんちん侍の場面ならちんちん侍）、「｜」でびろーん
- **フリックで指す**: 親のとき、自分のアイコンから相手の方へ指を払うと指せる（タップでもOK）
- **QRコードで共有**: 「遊ぶ」タブでゲームのURL、オンラインの待合室で招待リンクをQRコードにして見せられる
- **BGM**（オンオフ可）: タイトル画面で、和太鼓と三味線風の曲をその場で合成して鳴らす（音声ファイルなし）
- **ハンデ**: プレイヤー設定で、人間の制限時間を +0.5／+1／+2 秒長くできる（オンライン対戦では各自の席1の設定が使われる）
- **切腹ムービー**（オンオフ可）: 切腹した人のアイコンが斜めにスパッと斬れる
- **CPUのフェイント**（オンオフ可）: CPUが「ちんちん…」と溜めてから「侍！」を付けたり付けなかったりする。溜めている間に早とちりして言うとお手つき
- **キャラ**: 席ごとに名前・見た目（髪型・被り物・目・まゆ・口・アクセサリー・肌の色・服の色）・声（6種類）を編集画面で選べる。5つまで保存して呼び出せる。オンラインでも相手にそのまま見え、聞こえる
- **最高記録**: CPUの強さごとに、つづいた回数の最高記録をタイトル画面に表示
- **設定を覚える**: 人数・強さ・名前などは、次に開いたときもそのまま（ブラウザに保存）

## セリフ音声
`voices.js` に、オープンソースの日本語音声合成 Open JTalk（pyopenjtalk）で作ったセリフ音声が入っています。
席ごとに声が違い、各セリフに「ふつうの声」と「高い声」の2パターンがあります。残り時間が制限時間の20%を切ってから言うと高い声（焦って上ずった声）になります。喋る速さは全員そろえてあります（「ちんちん侍」が約0.9秒）。
スタート画面の「プレイヤー」の ▶ で、席ごとの声を確認できます。「ちんちん侍」は全員の声が重なります。
