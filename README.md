# ちんちん侍

4人で円になって遊ぶ飲み会ゲーム「ちんちん侍」のブラウザ版（自分 + CPU 3人）。
`index.html` をブラウザで開くだけで遊べます。

## ルール
- 親は「ちんちん」「おちんちん」「侍」「ちんちん侍」のどれかを言って、自分以外の誰かを指す
- 「ちんちん」→ 指された人は何も言わず、そのまま次の言葉で誰かを指す
- 「おちんちん」→ 指された人が「びろーん」
- 「侍」→ 指された人が「シャキーン」
- 「ちんちん侍」→ 親以外の全員で「ちんちん侍」
- 反応のあと、指された人が次の親になる
- 言い間違い・お手つき・時間切れは「切腹」。切腹した人が次の勝負の親

続くほど制限時間が短くなります。

## モード
- **セリフボタン**: 言葉ボタンを押して、指す人をタップ（順番はどちらが先でもOK）
- **音声入力**: 言葉を声で言って、指す人をタップ。Web Speech API を使うので Chrome / Safari で、`https://` か `file://` で開いてください
