# ちんちん侍

4人で円になって遊ぶ飲み会ゲーム「ちんちん侍」のブラウザ版。全体3〜6人、そのうち人間1〜6人＋残りはCPU（複数人は1台を囲んで遊ぶ）。
`index.html` をブラウザで開くだけで遊べます。

## ルール
- 親は「ちんちん」「おちんちん」「侍」「ちんちん侍」のどれかを言って、自分以外の誰かを指す
- 「ちんちん」→ 指された人は何も言わず、そのまま次の言葉で誰かを指す
- 「おちんちん」→ 指された人が「びろーん」
- 「侍」→ 指された人が「シャキーン」
- 「ちんちん侍」→ 親も含めて全員で「ちんちん侍」
- 反応のあと、指された人が次の親になる
- 言い間違い・お手つき・時間切れは「切腹」。一人切腹したら勝負あり

続くほど制限時間が短くなります。

## デスマッチ
ルールで「デスマッチ」を選ぶと、切腹した人は脱落して、残りの人で続けます。最後の一人になったら決着。
脱落した人の次（時計回り）の人が親で再開します。

## CPUの強さ
- **弱い**: いつも30%の確率で失敗
- **普通**: 最初は0%。続いた回数がそのまま失敗確率（10回目なら10%）
- **強い**: 20回までは失敗0%で「ちんちん」を高速で回す。21回目から（回数−20）%で失敗

強さとは別に「CPUは絶対に負けない」をオンにすると、CPUは失敗しなくなり、切腹するのは人間だけになります（強さはスピードと言葉の選び方だけに効く）。

## モード
- **セリフボタン**: 言葉ボタンを押して、指す人をタップ（順番はどちらが先でもOK）。複数人のとき「ちんちん侍」は各自が自分のアイコンをタップ
- **音声入力**: 言葉を声で言って、指す人をタップ。Web Speech API を使うので Chrome / Safari で、`https://` か `file://` で開いてください。CPUの読み上げは初期オフ。claude.ai 上ではプラットフォームの音声入力を使います

## そのほかの機能
- **案内を出す（初心者向け）**（オンオフ可、最初はオフ）: 誰の番か・何と言えばいいかを画面の下に出す。親の金枠・指された人の赤丸・指せる人のぷくぷくもこのときだけ出る
- **切腹ムービー**（オンオフ可）: 切腹した人のアイコンが斜めにスパッと斬れる
- **CPUのフェイント**（オンオフ可）: CPUが「ちんちん…」と溜めてから「侍！」を付けたり付けなかったりする。溜めている間に早とちりして言うとお手つき
- **プレイヤー設定**: 席ごとに名前・髪型（ちょんまげ／坊主／長髪／はちまき）・服の色を変えられる
- **最高記録**: CPUの強さごとに、つづいた回数の最高記録をタイトル画面に表示
- **設定を覚える**: 人数・強さ・名前などは、次に開いたときもそのまま（ブラウザに保存）

## セリフ音声
`voices.js` に、オープンソースの日本語音声合成 Open JTalk（pyopenjtalk）で作ったセリフ音声が入っています。
席ごとに声が違い、各セリフ2テイクから毎回ランダムに選ばれます。喋る速さは全員そろえてあります（「ちんちん侍」が約0.9秒）。
スタート画面の「声の試し聞き」で、席ごとの声を確認できます。「ちんちん侍」は全員の声が重なります。
