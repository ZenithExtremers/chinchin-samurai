# ちんちん侍

4人で円になって遊ぶ飲み会ゲーム「ちんちん侍」のブラウザ版。人間1〜4人＋残りはCPU（複数人は1台を囲んで遊ぶ）。
`index.html` をブラウザで開くだけで遊べます。

## ルール
- 親は「ちんちん」「おちんちん」「侍」「ちんちん侍」のどれかを言って、自分以外の誰かを指す
- 「ちんちん」→ 指された人は何も言わず、そのまま次の言葉で誰かを指す
- 「おちんちん」→ 指された人が「びろーん」
- 「侍」→ 指された人が「シャキーン」
- 「ちんちん侍」→ 親も含めて全員で「ちんちん侍」
- 反応のあと、指された人が次の親になる
- 言い間違い・お手つき・時間切れは「切腹」。一人切腹したら勝負あり

続くほど制限時間が短くなります。

## モード
- **セリフボタン**: 言葉ボタンを押して、指す人をタップ（順番はどちらが先でもOK）。複数人のとき「ちんちん侍」は各自が自分のアイコンをタップ
- **音声入力**: 言葉を声で言って、指す人をタップ。Web Speech API を使うので Chrome / Safari で、`https://` か `file://` で開いてください。CPUの読み上げは初期オフ。claude.ai 上ではプラットフォームの音声入力を使います
